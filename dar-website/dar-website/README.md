# DAR — واجهة موقع سكن طلابي

هذا مشروع Front-End مبني باستخدام HTML وCSS وJavaScript، ويحاكي صور التصميم المرفقة لثلاث صفحات:

- `index.html` — الصفحة الرئيسية والبحث عن السكن.
- `register.html` — صفحة إنشاء حساب.
- `login.html` — صفحة تسجيل الدخول.

## التشغيل

1. فك ضغط الملف إذا كان مضغوطًا.
2. افتح `index.html` باستخدام متصفح حديث.
3. للتطوير، يفضّل فتح المجلد في Visual Studio Code واستخدام إضافة Live Server.

## التفاعلات الموجودة

- تصميم متجاوب للشاشات الكبيرة والهواتف.
- فلاتر حسب نوع السكن والمنطقة والجامعة والميزانية.
- إضافة وإزالة الإعلانات من المفضلة كتفاعل تجريبي داخل الصفحة.
- إظهار وإخفاء كلمات المرور.
- تحقق مبدئي من مدخلات التسجيل وتسجيل الدخول.
- قائمة تنقل مناسبة للهواتف.

## ملاحظات مهمة

هذه نسخة واجهة أمامية فقط. إنشاء الحساب وتسجيل الدخول الفعليان، وتسجيل المفضلة بشكل دائم، وتسجيل الدخول بحساب Google، وجلب الإعلانات من قاعدة بيانات، تحتاج إلى Backend وقاعدة بيانات وربط API. التفاعلات التي تعتمد على هذه الخدمات تعرض رسالة توضيحية بدلًا من الادعاء بتنفيذ عملية حقيقية.

صور المباني والغرف المرفقة داخل مجلد `assets` مقتطعة من صور التصميم التي أرسلها المستخدم لغرض مطابقة شكل النموذج.
